🔍 研究背景
  • 中国约60%城市社区建成于2000年前，老旧化问题突出
  • 改造资源有限，项目优先排序至关重要
  • 现有方法以定性评估为主，缺乏多方参与的定量框架
  • 多利益相关者利益诉求冲突，阻碍改造推进

三类主体偏好存在显著差异，单一评价标准无法全面体现多方诉求，本研究将三者纳入统一量化框架。

⚙️ 核心方法：逻辑偏好评分法（LSP）
传统方法
✗ AHP / MCE
✗ 指标多则权重衰减
✗ 线性聚合，逻辑简化
✗ 难以体现偏好异质性
→
LSP 方法
✓ 非线性逻辑聚合
✓ 支持大规模指标体系
✓ 同时性 + 可替代性
✓ 精准刻画决策偏好
⊕ 同时性（Conjunction）
多个条件须同时满足（逻辑"与"），量化为合取度，体现决策的强制性要求
⊕ 可替代性（Disjunction）
条件间可相互替代（逻辑"或"），量化为析取度，体现决策的灵活弹性

📌 主要发现
三类利益相关者偏好存在显著差异，揭示单一决策标准的根本局限
不同情境（单决策 vs 多决策）下，社区适宜性排序呈现相对稳定性
百度街景实地验证确认评价结果与现实需求高度吻合
系统具备地域迁移性，参数可调，适用于其他超大城市
📋 四项政策建议
01
高适宜性社区可直接实施改造，优先提升整体效率
02
中适宜性社区需充分多方协商，切实保障公平性
03
资金充足时优先考虑居民偏好，以公平性为导向
04
资金受限时优先考虑投资者偏好，以效率性为导向
